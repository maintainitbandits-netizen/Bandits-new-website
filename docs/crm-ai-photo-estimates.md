# CRM AI photo estimates

This feature prepares a **suggestion for a person to review**, not an automatically approved or sent quote. It is disabled until the code is published and an administrator deliberately completes the Cloudflare Workers Free setup below. Building it did not create a Cloudflare account, set credentials, change billing, enable the feature, or send a live AI request. Tests use fictional data and simulated providers; the real Cloudflare/model contract, image quality, allowance per quote, and physical-phone workflow have **not** yet been verified.

## Preparing a draft

1. Wait for **Synced across devices**, open **Estimates → Photo estimate with AI**, and choose an existing client and a service. The optional property and client selection stay in the CRM and are not separately sent to Cloudflare. If their names or addresses appear in the description, rate names or images, however, those details are sent as part of that material. Avoid unnecessary personal or sensitive information, and obtain any needed permission to share the photos.
2. Describe the requested work and provide known measurements, access details and other conditions; choose **1–3** photos, each no larger than 20 MB. Thumbnails show what was chosen. JPEG, PNG, WebP and HEIC/HEIF are accepted if the device can decode them; if a HEIC photo fails, choose a JPEG or PNG. Selected pictures are resized to at most 1,200 pixels on the long edge and re-encoded as JPEG on the device; embedded metadata is not copied. Text, addresses, people and other identifying details *visible in the picture* remain visible. The browser sends the re-encoded images, not the filenames or original files. The prepared JPEGs are bounded at 750,000 bytes each so the JSON request fits below the Vercel Function payload limit.
3. **Rates are optional.** The original starter rates are placeholders, not real prices, and cannot be used here unchanged. In **Rates**, replace the entire card with actual, verified prices; use `name | price`, one line per rate, with no duplicates and up to two decimal places. To use a saved card in an AI draft, explicitly check the box confirming that all of its prices are current. Only the **names and numeric identifiers** are sent to Cloudflare, not their prices (unless a name itself contains a price). A suggested rate match is mapped back to the saved price on the device. A name match, unit, quantity or applicability can still be wrong. If there is no verified card or an item cannot be matched, its price stays blank for manual entry. If the card changes before the editor opens, matching prices are left blank; if it changes in the editor, saving is blocked until the prices are reviewed again. Rates and totals are always the person's responsibility.
4. Read and check the disclosure for **each request**, then tap **Generate draft**. This sends the selected, prepared photos, work description, service and (only if selected) rate names to **Cloudflare Workers AI**. No request is sent by choosing photos, and no customer is contacted. The app does not automatically retry or fall back to another provider. Closing after sending cannot guarantee the provider stops processing or using the account's allowance; a paid account may incur charges. If the response is missing, check Workers AI usage before deliberately trying again.
5. Review the suggested scope, quantities, matching rate names, questions and cautions. A numeric quantity absent from the description is left blank for manual entry; type known quantities with digits, not just words. A number found in the description might still refer to something else, use the wrong unit, or be wrong, so this check is not proof of a measurement. Photos cannot reliably reveal size, measurements, hidden damage, safe access, site restrictions, supplies or all required work. Take measurements or inspect as needed. The AI is not a professional site assessment and can be wrong even when it returns a number or rate match.
6. Tap **Review in estimate editor**. This opens an **unsaved Draft** in the existing estimate editor. Check and edit the client, property, scope, quantities, prices, customer notes and total; tax is not automatic. Enter any missing quantity or price. Confirm the review checkbox and explicitly **Save estimate**. If anything changes after the checkbox was checked, review and check it again. Saving does not send the estimate or schedule a job. Later, the normal **View → Copy text / Print / PDF** controls require a separate manual action; schedule only through the existing reviewed workflow.

The AI summary, questions, cautions, line explanations and work description are copied to editable **team-only notes** in the editor, not customer-facing notes. Team-only means not shown on the estimate document; all authenticated CRM team accounts have broad access to shared records, and a saved estimate and its team-only notes are included in CRM JSON backups. If this text exceeds 5,000 characters, the app warns before shortening it. Cancelling the suggestion/editor does not create a CRM estimate. AI-selected photos are not saved as job photos or included in backups; the separate Before / after job-photo feature is unchanged. Existing job quotes are not changed by generating a photo draft.

## Free-plan prerequisite, privacy and access

- **Use and maintain an account on Workers Free. The application cannot verify the account's current billing plan.** Its confirmation setting is an administrator's assertion, not a provider-side spending limit. If the account is paid, later upgraded, or otherwise configured for paid inference, charges may apply. The owner must check the Cloudflare dashboard before enabling and remain responsible for the plan and account settings. Do not upgrade or enable any paid service without separate approval; disable this feature and revoke the token if the account no longer meets the Free prerequisite.
- Cloudflare currently describes a shared **10,000 Neurons per day** Workers AI allowance, resetting at **00:00 UTC**; on Workers Free, further operations fail when the allowance is reached. A Workers Paid account also has an allowance but bills overage. Other Workers AI use on the same account shares the allowance; model capacity and rate limits can also cause errors. Photos, output size and provider changes affect usage, so the number of drafts per day is unknown. See current [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) and [model availability](https://developers.cloudflare.com/changelog/post/2026-07-28-models-require-workers-paid/).
- This code calls Cloudflare's direct Workers AI REST endpoint for the vision model `@cf/google/gemma-4-26b-a4b-it`, listed for Workers Free when implemented. It does **not** use an AI Gateway or prepaid gateway credits, automatically upgrade, retry, or fall back to a different provider. The actual account/model access, multiple-photo support and quality must be checked later in an approved live test.
- Cloudflare says it does **not train models on Workers AI customer content** and that standard stateless inference inputs and outputs are not retained after processing, subject to safety, security and legal exceptions. Stateful features, logging and caching can differ; see [Cloudflare's current data policy](https://developers.cloudflare.com/workers-ai/platform/data-usage/). This request uses `store: false`. Vercel also receives the request; the application code does not intentionally log or persist the photos or provider request. Review providers' current policies before sending customer information.
- The server checks the Supabase bearer token against the CRM project and rejects anonymous or unverified users. **Every authenticated CRM team user can use the feature once enabled.** There is no durable per-user quota or application-level rate limiter; a user with valid CRM access can call the endpoint directly and exhaust the shared allowance. Protect CRM accounts and monitor Workers AI usage. The disclosure checkbox is a user-interface confirmation, not a defense against a malicious authenticated user.

## Administrator setup — for later, after publication is approved

These instructions are for a later setup; they have **not** been performed by this change. No provider secret should be pasted into the CRM, repository, issue, pull request, screenshots, logs, or chat.

1. Confirm the owner has approved publication, review the code, and use the normal release process. Until configured, requests fail closed without reaching Cloudflare. A Vercel preview can share the **live CRM database**; do not save, delete, or otherwise modify live records as a test.
2. In the Cloudflare dashboard, select an account and verify that its **Workers plan is Free**, not Workers Paid or an enterprise/other paid arrangement. Prefer a dedicated Free account with no linked payment method if the owner's circumstances permit; verify eligibility and current terms in Cloudflare. Do not create or enable a paid subscription, paid gateway, credits or auto-purchases. The app cannot enforce or re-check the billing plan and will not notice a later upgrade.
3. Follow Cloudflare's [REST API setup](https://developers.cloudflare.com/workers-ai/get-started/rest-api/) to obtain the selected account ID and create a **Workers AI API token** scoped to that account and only the needed permission. The token is a secret; use an API token, not the global API key. The account ID must be the 32-character hexadecimal ID.
4. In the **primary frontend Vercel project**, privately enter `CRM_CLOUDFLARE_AI_TOKEN` as a **sensitive server-only environment variable** and `CRM_CLOUDFLARE_ACCOUNT_ID` as a server-only variable. Once the owner has verified and committed to keeping the account on Workers Free, set both `CRM_AI_FREE_PLAN_CONFIRMED` and `AI_QUOTES_ENABLED` to the exact value `true` for the intended deployment environment. Neither switch checks Cloudflare's plan. Missing/invalid credentials or either switch not exactly `true` prevent the provider request. Never use `REACT_APP_` variables or expose the token to the browser. Vercel environment changes require a new deployment.
5. Only after separate approval, run a small **fictional-photo** live test, verify the response and photo count, and inspect the Cloudflare dashboard's plan and Neuron usage. Test the real phone workflow separately without altering real customer records. Mock tests cannot prove provider JSON compatibility, multi-image behavior, quality, usage, network timeouts or production configuration.
6. Monitor usage and plan status. To stop new use, set `AI_QUOTES_ENABLED` to `false` (and/or remove the confirmation), redeploy, and revoke the token in Cloudflare if an immediate provider-side cutoff is needed. In-flight requests may still finish. If a quota, capacity, setup or provider error occurs, no estimate is saved and there is no automatic retry or paid fallback.

The Vercel function bounds request size, requires explicit consent in the payload, sends no server credentials to the browser, independently validates the provider output and returns a no-store response. These controls do not eliminate prompt injection, estimation errors, provider retention, spending risk, or the existing CRM's shared-team access model. Use one device at a time for saves and wait for the existing sync indicator; cross-device writes are not transactional.

## Switching providers later

The provider-specific request and response handling is isolated in `frontend/lib/crm-quote-cloudflare.js`; CRM validation, the estimate editor, and saved estimate records use provider-independent fields. A future Gemini integration would require its own code, privacy/cost disclosure, credentials and approval; it is **not** configured as a fallback. Switching or disabling the provider does not itself delete saved estimates. Review current Gemini terms first: Google says it may use free-tier inputs and outputs to improve products.
